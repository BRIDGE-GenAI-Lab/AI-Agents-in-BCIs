None of the brief's suggested default lengths (4, 5, 6, 8) clear 300
error-bearing ALS episodes. Only length=3 and length=2 do.

Recommendation: use length=3 for downstream tasks (Task 5 sampling, etc.).
It clears the gate with margin (366 error-bearing, 1088 total, all 47 ALS
participants retained) while still giving a 3-character decoded string --
the shortest unit for which "the model got at least one selection wrong out
of several" is a meaningful distinction to show a reviewer. length=2 clears
with more margin (446) but a 2-character episode has only two possible error
counts (0 or up to 2) and is close to a single-selection judgment, which
weakens the oversight-review task this module feeds. length=5, the
function's documented default, is kept as the function signature default
per the brief's exact interface, but callers needing >=300 error-bearing
episodes must pass length=3 explicitly.
